# echinos

[Personal website](https://jon-kane.github.io/echinos/) and data science blog.

Built with [Quarto](https://quarto.org/) and R... and sometimes Python.

---

## 📁 Repository Structure

```text
echinos/
├── _quarto.yml        # Quarto website configuration & navigation
├── _common.R          # Shared R ggplot theme and plotting setup
├── styles.css         # Custom styling (accents, layout, TOC, responsive menu)
├── references.bib     # BibTeX citations
├── index.qmd          # Homepage / writings listing
├── about.qmd          # About page
├── posts/             # Blog post directories
├── images/            # Site logos and icons
├── ARCHIVE/           # Archived experiments and previous assets
└── _freeze/           # Quarto computational cache for deterministic builds
```
